# Acompanhamento hierárquico das atividades

As atividades detalhadas geradas a partir da Estrutura do Relatório 1 — V1 são tratadas como **etapas de execução** dos itens de coordenação, e não como registros independentes na tela principal de acompanhamento.

## Comportamento adotado

| Área | Comportamento |
| --- | --- |
| Lista de Atividades | Exibe somente os 47 itens de coordenação, que funcionam como atividades-mãe. |
| Ficha da atividade-mãe | Exibe todas as etapas-filhas vinculadas, com código, estado, executor, progresso e prazo. |
| Atualização de etapa | É iniciada no contexto da ficha-mãe pelo botão **Atualizar etapa**, preservando os controles de autorização já existentes. |
| Dados preservados | Responsáveis formais, alocações, revisores, marcos, materiais, evidências, interfaces e histórico permanecem nos registros respectivos. |

O acompanhamento passa, portanto, a seguir a lógica editorial do estudo: a atividade-mãe representa a frente coordenada e suas etapas representam a execução dos tópicos que compõem o capítulo.
