# Reconciliação da itemização pelo índice analítico V1

## Fonte canônica e escopo

A Estrutura do Relatório 1 — V1 é a referência canônica da itemização analítica do Portal Naval. A reconciliação preserva as 30 frentes e as 47 atividades-mãe como camada de gestão, enquanto as etapas de execução reproduzem os subitens do índice analítico.

## Resultado da reconciliação

| Elemento | Resultado |
|---|---:|
| Subitens analíticos canônicos | 286 |
| Etapas cadastradas após a remoção autorizada | 286 |
| Subitens faltantes | 0 |
| Subitens adicionais | 0 |
| Divergências de código, capítulo, ordem ou título | 0 |

Foram atualizados 210 títulos, capítulos ou posições de ordenação para reproduzir a redação integral do índice V1. O limite do campo de título foi ampliado para 1.000 caracteres exclusivamente para preservar os textos canônicos sem abreviação.

## Preservação operacional

A reconciliação não alterou responsáveis, prazos, estados, progresso, alocações, revisões, materiais, evidências, interfaces ou marcos das etapas remanescentes. As 44 etapas suplementares removidas por autorização do usuário foram registradas individualmente em `scope_migration_history` antes da exclusão.
